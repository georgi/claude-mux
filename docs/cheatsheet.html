cmux

Ghostty bindings and prefix keys. Prefix: Ctrl-b. Ctrl-b Ctrl-b sends a literal Ctrl-b.

Ghostty: tabs

⌘1…⌘9 ⌘0Go to a tab (⌘0 is tab 10)
⌘TNew Claude session
⌘⇧ONew session in another directory
⌘PResume or fork a past session
⌘⇧T / ⌘GNew shell / lazygit
⌘⇧[ / ⌘⇧]Previous / next tab
⌘J / ⌘⇧JNext / previous tab with an alert
⌘⇧← / ⌘⇧→Move the tab (server: narrow / widen the tree)
⌘RRename the tab
⌘SList the open tabs
⌘⇧CScroll back through output
⌘W / ⌘⇧WStop the pane's session / quit (detach)

Ghostty: panes

⌘D / ⌘⇧DSplit right / below
⌘⌥H J K LGo to the pane left / down / up / right
⌘⌃H J K LResize the pane by 5 cells
⌘⇧↩Zoom the pane
⇧↩Newline in Claude

Ghostty: plans (server)

⌘BFocus the plan tree, or go back to the pane
⌘⇧BHide / show the plan tree

cmux plans
